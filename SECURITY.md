# Security Policy

## Supported versions

Security fixes go into the latest release. Please update to it before
reporting.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Email
**security@hibira.io**, or use GitHub's private vulnerability reporting on
this repository, with the affected version, what the issue lets someone do,
and the steps to reproduce it.

We reply within 3 business days, send an assessment within 10 business days,
and agree the disclosure date with you. We credit you in the release notes
unless you'd rather stay anonymous.

The full policy, covering every Hibira SDK and the hosted service, is at
https://github.com/hibira-io/.github/blob/main/SECURITY.md.
